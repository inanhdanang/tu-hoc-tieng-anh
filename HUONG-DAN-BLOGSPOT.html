🚀 Hướng dẫn đăng Website lên Blogspot

Làm theo từng bước — không cần biết code!

CÁCH 1 – ĐƠN GIẢN NHẤT

Dùng Google Drive + Blogger Widget (Khuyến nghị)

  1. Upload toàn bộ file HTML (index.html, Day1.html… Day15.html) lên Google Drive
  2. Chia sẻ từng file: Chuột phải → Chia sẻ → Bất kỳ ai có đường dẫn
  3. Lấy link chia sẻ, đổi drive.google.com/file/d/ID/view thành drive.google.com/uc?id=ID
  4. Trong Blogger: Trang → Tạo trang mới → Chế độ HTML, dán iframe:

    <iframe src="LINK_DRIVE" width="100%" height="800" frameborder="0"></iframe>
⚠️ Cách này đơn giản nhưng Google Drive đôi khi không render HTML trực tiếp. Nếu không được, dùng Cách 2.
CÁCH 2 – TỐT NHẤT (Miễn phí, chuyên nghiệp)

Dùng GitHub Pages (hoàn toàn miễn phí!)

  1. Đăng ký tài khoản miễn phí tại github.com
  2. Tạo repository mới, đặt tên ví dụ: tu-hoc-tieng-anh
  3. Upload toàn bộ file HTML vào repository
  4. Vào Settings → Pages → Source: Deploy from branch (main)
  5. Website của bạn sẽ có địa chỉ: username.github.io/tu-hoc-tieng-anh
  6. Trong Blogger, thêm Tiện ích HTML/JavaScript, dán link vào
✅ Đây là cách tốt nhất! GitHub Pages miễn phí, nhanh, và khi bạn thêm Day16.html mới — chỉ cần upload thêm file là xong!
CÁCH 3 – TRỰC TIẾP TRONG BLOGGER

Nhúng HTML vào bài đăng Blogger

  1. Trong Blogger: Bài đăng → Tạo mới → Chuyển sang chế độ HTML
  2. Dán toàn bộ nội dung của index.html vào
  3. Lưu và xuất bản
  4. Mỗi bài Day1, Day2... tạo một bài đăng riêng
  5. Sửa đường dẫn url: "Day1.html" thành link đầy đủ của bài đăng đó
⚠️ Blogger có thể xóa một số tag JavaScript. Nếu gặp lỗi, hãy dùng Cách 2 (GitHub Pages).
THÊM BÀI MỚI

Thêm Day16, Day17... không cần sửa code!

  1. Upload file Day16.html vào cùng nơi lưu các file khác
  2. Mở file index.html, tìm dòng có chữ THÊM BÀI HỌC MỚI VÀO ĐÂY
  3. Copy đoạn mẫu và điền thông tin bài mới
  4. Lưu lại — trang chủ tự cập nhật, thẻ bài mới tự xuất hiện!
✅ Toàn bộ cấu trúc web, màu sắc, bố cục — đều được tự động. Bạn chỉ cần điền 4 dòng thông tin!
