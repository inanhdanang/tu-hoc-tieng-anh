CÁCH DÙNG ANY VÀ SOME TRONG CÂU

Are there any... / Is there any...
📌 Hôm nay học gì? Cách hỏi xem có "bất kỳ" thứ gì không với từ ANY, và cách trả lời bằng SOME (vài/một ít) hoặc ANY (không có cái nào).

🍎 Dành cho N Đếm được (Số nhiều)

Are there any + N(s/es)?
Are there any books on the table?
Are there any students in the classroom?
✅ Luôn dùng Are there và Danh từ đếm được phải có -s/-es.

💧 Dành cho N Không đếm được

Is there any + N(không đếm được)?
Is there any water in the bottle?
Is there any milk in the fridge?
✅ Nước, sữa, đường, bài tập (homework)... dùng Is there.

✅ Trả lời KHẲNG ĐỊNH (Có)

Yes, there are/is + SOME + N
Yes, there are some books.
Yes, there is some milk.
✅ Dùng SOME (một vài, một ít) cho câu Khẳng định.

❌ Trả lời PHỦ ĐỊNH (Không)

No, there aren't/isn't + ANY + N
No, there aren't any apples.
No, there isn't any sugar.
✅ Dùng ANY (bất kỳ) cho câu Phủ định và Câu hỏi.
⚠️ Lỗi thường gặp:
❌ "Are there any book?" → ✅ "Are there any books?" (Bắt buộc số nhiều).
❌ "Are there any water?" → ✅ "Is there any water?" (Water không đếm được).
❌ "There are any eggs." → ✅ "There are some eggs." (Khẳng định dùng SOME).
