⚠️ ĐỌC TRƯỚC

Blogspot KHÔNG thể host file HTML riêng lẻ

Blogspot (Blogger) là nền tảng blog – không phải web hosting. Bạn không thể upload Day1.html, Day2.html... như trên GitHub Pages.

Có 2 hướng đi đúng:

  • Cách A (Khuyến nghị): Dùng GitHub Pages (miễn phí) để host tất cả file HTML, rồi nhúng link vào Blogspot
  • Cách B: Chuyển đổi mỗi bài Day thành 1 bài đăng Blogger và lưu nội dung HTML vào đó
CÁCH A – TỐT NHẤT (Miễn phí)

GitHub Pages + nhúng vào Blogspot

  1. Đăng ký tài khoản tại github.com
  2. Tạo repository mới, ví dụ: tu-hoc-tieng-anh
  3. Upload tất cả file HTML (index.html, Day1.html … Day15.html) lên repository
  4. Vào Settings → Pages → Source: main branch → Save
  5. GitHub cấp cho bạn URL: username.github.io/tu-hoc-tieng-anh
  6. Trong Blogspot: tạo Trang tĩnh mới, dán đoạn sau vào chế độ HTML:
<iframe src="https://username.github.io/tu-hoc-tieng-anh/index.html"
  width="100%" height="900" frameborder="0"
  style="border:none;border-radius:12px;"></iframe>
✅ Đây là cách tốt nhất! Khi bạn thêm Day16.html mới: chỉ cần upload thêm file lên GitHub là xong — Blogspot tự cập nhật ngay!
CÁCH B – TRỰC TIẾP TRONG BLOGGER

Mỗi bài học = 1 bài đăng Blogger riêng

  1. Trong Blogger: Bài đăng mới → Chuyển sang chế độ HTML
  2. Dán toàn bộ nội dung HTML của bài Day vào (bỏ thẻ <!DOCTYPE>, <html>, <head>, <body>)
  3. Chỉ giữ lại phần <style>...</style> và nội dung bên trong <body>
  4. Đăng bài → Lấy URL bài đó (ví dụ: yourblog.blogspot.com/2024/01/day1.html)
  5. Mở index.html, sửa url: "Day1.html" thành URL đầy đủ vừa lấy
  6. Làm tương tự cho tất cả bài Day
  7. Bài index.html cũng tạo 1 bài đăng/trang riêng tương tự
⚠️ Blogger tự động xóa một số thẻ JavaScript và thuộc tính onclick khi lưu. Nếu quiz/nút không hoạt động — dùng Cách A!
⚠️ LỖI THƯỜNG GẶP TRÊN BLOGSPOT

Các lỗi phổ biến và cách xử lý

  • JavaScript bị xóa: Blogger strip các thẻ <script> inline khi lưu bài — giải pháp: đặt JS trong <script> ở cuối template hoặc dùng GitHub Pages
  • onclick bị xóa: Blogger xóa các event handler inline — dùng addEventListener thay vì onclick="..."
  • CSS bị ghi đè: Theme Blogspot có CSS riêng có thể đè lên CSS của bạn — thêm !important hoặc dùng namespace riêng
  • Font Google bị chặn: Một số browser/ISP chặn Google Fonts — thêm fallback: font-family: 'Nunito', 'Segoe UI', sans-serif
  • iframe không hiển thị: Blogspot chặn iframe từ HTTP (chỉ HTTPS) — GitHub Pages mặc định dùng HTTPS nên không bị lỗi này
  • SpeechSynthesis không hoạt động: Tính năng đọc text cần HTTPS — GitHub Pages hỗ trợ, Blogspot cũng hỗ trợ HTTPS
THÊM BÀI MỚI

Thêm Day16, Day17... dễ dàng Hỗ trợ 300+ bài

  1. Tạo file Day16.html mới (copy từ Day1.html rồi thay nội dung)
  2. Upload lên GitHub repository (kéo thả vào trang repo)
  3. Mở index.html → tìm THÊM BÀI HỌC MỚI VÀO ĐÂY
  4. Copy đoạn mẫu và điền 4 dòng thông tin bài mới
  5. Lưu lại và upload index.html mới lên GitHub
✅ index.html đã được nâng cấp với Lazy Rendering: dù có 300+ bài vẫn tải nhanh! Trang chỉ render 30 bài đầu, khi cuộn mới load thêm. Còn có ô tìm kiếm bài học theo tên/chủ đề!
BLOGSPOT XML THEME

Sử dụng file theme XML đi kèm

File blogspot-theme.xml đi kèm là một Blogger theme tối giản, đã:

  • Loại bỏ CSS mặc định của Blogger gây xung đột
  • Giữ lại header/footer cơ bản của Blogger (đăng nhập, menu)
  • Tương thích với CSS của website tự học
  • Có viewport meta tag đúng chuẩn mobile

Cách dùng: Blogger → Giao diện → Chỉnh sửa HTML → Paste toàn bộ nội dung file XML → Lưu

⚠️ Backup theme cũ trước khi thay! Blogger → Giao diện → Dấu 3 chấm → Sao lưu
